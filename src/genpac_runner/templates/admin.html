启动与生成模式

选择由项目直接生成自定义 PAC，或由 genpac 根据 GFWList 生成。

例如：SOCKS5 192.168.31.200:7893; DIRECT。自定义模式将其用作默认代理；genpac 模式将其交给 genpac。
仅在 genpac 模式使用，须为 http(s) URL。

自定义域名规则

每行一个域名，也可以用英文逗号分隔。写 baidu.com 会匹配根域名及所有层级的子域名。

命中时直接连接，不经过代理。
命中时返回 PROXY 0.0.0.0:0；这不是防火墙级阻断。

定时更新与时区

留空关闭定时更新。修改后立即生效，不需要重建容器。

标准 5 段格式：分 时 日 月 周。例：0 */6 * * * 表示每 6 小时尝试更新。
IANA 时区名称，例如 Asia/Shanghai、Asia/Singapore 或 UTC。

Webhook 通知

成功和失败通知分别配置 URL 与 JSON 请求体。URL 留空则关闭该类通知。

JSON 顶层必须为对象；兼容钉钉等 JSON Webhook。
如果 JSON 含 markdown.text，会自动追加本次失败摘要。

手动生成

使用数据库中当前已保存的设置重新生成 PAC，不会保存尚未提交的表单改动。
